## 分项说明

### G — 遥测 / Hook

- **已发现**：hook 含 `model_id`、`input_tokens`、`output_tokens`；应写入事实层并填 P4
- **不能单独完成全量**：`default` 仍大量存在
- **周数 1–2**：增强 merge 优先级、token 落库、子代理 model、文档

### C — 代码

- 最高迁移性之一；Cursor 主产物是代码
- 风险：极短 diff、格式化工具抹平风格、多模型协作同一文件
- 建议先 LPcodedec 级轻特征，再可选 CodeT5

### B — 文本

- 增强现有 blindtest；与 C 互补（计划/解释 turn）
- 风险：Auto 人设与统一系统提示

### H — 融合

- 产品「全量」的定义落点；无此则准确率数字无法对用户诚实展示
- 必须双轨：`factual` / `inferred_*`

### D — 探针

- 用于建库与池先验；**逐步归因主路径否决**（路由污染）
- 可在手选模型下跑 LLMmap 风格题集，丰富指纹

### E — 时序

- 先挖 hook `duration_ms` + 现有 `ttft_ms`
- 完整 ITT 等有稳定流式时间戳再立项

## 建议实现顺序（检索结束后的下一阶段）

```text
1. G: hook model_id/tokens 事实合并（消灭「有事实却显示 opaque」）
2. H: 报表分轨 + auto-opaque → pending_infer 语义
3. C+B: 扩展 blindtest 特征与手选 GT 语料
4. H: 融合默认开启（Auto 任务自动 inferred）
5. D/F: 周期先验（可选）
6. E: ITT（可选）
```
